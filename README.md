# Portfolio Website

A clean, static personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project is a developer portfolio site showcasing experience, projects, certifications, and contact information. The site is designed to be simple, responsive, and easy to deploy as a static website.

## Files

- `index.html` - Main portfolio page.
- `style.css` - Styling for layout, typography, cards, and responsive design.
- `script.js` - Site interaction logic and contact form behavior.
- `profile.jpg` - Profile image used on the portfolio page.

## Features

- Personal introduction and call to action
- Experience section with professionally written bullet points
- Certification and patent showcase cards
- Contact form with frontend entry handling
- Modern portfolio styling and layout

## Usage

1. Open `index.html` in a web browser.
2. Review and update the content as needed to match your personal details.
3. For deployment, host the files on any static web server or GitHub Pages.

## Deployment

- GitHub Pages: Push this repository to GitHub and enable Pages from the repository settings.
- Static hosts: Upload the files to Netlify, Vercel, Firebase Hosting, or any static file host.

## Notes

- The contact form is currently frontend-only and does not send email without a backend service.
- The main entry point is now `index.html` for optimal Vercel and static host compatibility.
